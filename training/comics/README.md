# SANA: эксперимент со сценаристом в бесплатном Colab

Это **подготовленный пилот**, а не уже обученная или опубликованная модель.
Обучение начнётся только при выполнении ноутбука на GPU. Результаты сохраняются
в отдельный адаптер; публичная SANA продолжает использовать свою текущую модель.

Открыть: [SANA comic pilot в Google Colab](https://colab.research.google.com/github/batyrkekw/SANA/blob/main/training/comics/sana_comic_colab.ipynb).

1. В Colab: **Среда выполнения → Сменить тип среды → T4 GPU → Сохранить**.
2. **Среда выполнения → Выполнить все**. Если Google попросит разрешить запуск
   кода из GitHub, это код данного репозитория. Секреты Supabase/Cloudflare не нужны.
3. Дождаться строки `training_completed_pending_review` и скачать предложенный ZIP.
4. Открыть `comparison.html`: оценить варианты A/B, затем смотреть ключ.

Если бесплатный GPU недоступен, обучение не стартует. Не переключайтесь на
локальную среду: этот сценарий рассчитан на облачный GPU, а не на Mac. Не нужно
покупать тариф или вводить платёжные данные. Colab не гарантирует GPU и время
работы; закрытие сессии/исчерпание лимита может остановить эксперимент. Скачайте
результаты до отключения. Ноутбук не монтирует Drive и ничего туда не записывает.

## Что именно обучается

- `Qwen/Qwen3-4B-Instruct-2507`, фиксированная ревизия в `protocol.py`, Apache-2.0.
- QLoRA: база в 4 битах NF4, адаптер rank 8 в attention-проекциях.
- Batch 1, накопление 4, 2 эпохи, learning rate 5e-5. Всего 8 шагов оптимизатора
  для текущих 16 сценариев; это небольшой проверочный эксперимент, не полноценный корпус.
- Loss считается только по ответу ассистента. Промпт и padding замаскированы.
- Сценарии не обрезаются незаметно. При превышении длины запуск останавливается.
- FP16 для T4, BF16 только если GPU поддерживает. База не дообучается целиком.
- До и после: одинаковые запросы на 4 отдельных темах, greedy decoding,
  структурная проверка JSON и ручное слепое сравнение с перемешанными A/B.

Этот компактный контракт сценариста отдельный от production-промпта. Поля ответа
совместимы с `EducationalContent`, но отдельной интеграции в рабочую генерацию нет.
Адаптер **не совместим** с текущей публичной Qwen3-30B-A3B и не может быть просто
загружен в её Cloudflare endpoint. Бесплатный Colab используется для интерактивного
эксперимента, а не для постоянного API сайта. Для публикации собственных весов
потребуется отдельное решение по инференсу и его стоимости.

## Бесплатный хостинг после обучения: проверка 6 ноября 2026

Для этой Qwen возможен отдельный Hugging Face ZeroGPU Space, который сайт вызывает
через API. По текущей документации бесплатный личный аккаунт с подтверждённой
почтой, старше 30 дней и без ограничений может разместить до двух ZeroGPU Spaces.
Бесплатная квота — **5 минут GPU в сутки на аккаунт**, с очередями. Если backend
использует один HF-токен, все его запросы расходуют квоту этого одного аккаунта.
Это вариант для ограниченного пилота, а не подтверждённая ёмкость для 80–100
комиксов в день. Доступ пользователя к ZeroGPU ещё не проверен, Space не создан.

Возможная схема: SANA → Cloudflare Worker → ZeroGPU с Qwen + адаптером → результат.
Картинки остаются в Cloudflare. При недоступности собственной текстовой модели
можно использовать текущую Qwen Cloudflare как явно обозначенный резерв.
Ни этот маршрут, ни резервное переключение пока не реализованы. Colab используется
для обучения и не является сервером сайта; Mac не нужен для такого облачного маршрута.

Cloudflare также поддерживает собственные LoRA некоторых других базовых моделей;
функция пока бесплатна в beta. Реально проверен
`@cf/mistral/mistral-7b-instruct-v0.2-lora` **без обученного адаптера** на аккаунте
проекта: оба запроса вернули HTTP 200, но не прошли проверку формата и содержания.
Русский пример (71.46 с) свёл цель урока о равных долях к неправильному выводу о
«делении по большей части». Казахский (35.26 с) сменил тему разрядов на сложение,
смешал языки и выдал плохой текст. Это два наблюдения, не общий рейтинг моделей.
Переход на Mistral для публичной SANA не выполнен. 16 примеров дообучения не дают
оснований обещать исправление этих недостатков. Полные результаты:
`benchmarks/comics/results/2026-11-06/mistral-base-{ru,kk}.json`.

- [ZeroGPU: доступ и квоты](https://huggingface.co/docs/hub/spaces-zerogpu)
- [API: чья квота расходуется](https://huggingface.co/docs/hub/spaces-api-endpoints#zerogpu-spaces)
- [Cloudflare: LoRA beta](https://developers.cloudflare.com/workers-ai/features/fine-tunes/loras/)

## Данные и границы выводов

`data/stories.jsonl`: 20 оригинальных синтетических текстовых примеров, написанных
ассистентом для SANA. 16 train (12 RU, 4 KK), 4 eval (3 RU, 1 KK), 4–6 классы.
Каждый содержит сценарий, английские описания кадров, проверяемый учебный факт,
визуальное ограничение и механизм шутки. Темы разделены до обучения; eval не
используется для градиентов или выбора чекпоинта.

Это редакторские заготовки, **не отзывы учителей и не оценка школьников**. Не было
реального тестирования юмора на аудитории. Нет ученических данных, чужих мемов или
сгенерированных картинок из проваленных тестов. Казахские тексты требуют дальнейшей
проверки преподавателем языка. Небольшой синтетический набор может вызвать
переобучение и не доказывает улучшения на других темах, возрастах или языках.

В четырёх учебных кадрах важны: понятная цель героя, попытка, наблюдаемое открытие,
вывод и добрый комический поворот. Это не повод подменять факт шуткой. Для оценки
каждого варианта поставьте 0–2 по пяти критериям: точность, понятность для возраста,
сюжет, юмор, рисуемость. Любая критическая фактическая ошибка отклоняет пример.
Победа по loss/JSON сама по себе не означает более смешной или полезный комикс.

**Рисующая модель не обучается.** Тест FLUX показал ошибки состояний и количества
воды, поэтому рисунки не включены как образцы. Для её обучения нужны исправленные
визуальные эталоны; этот текстовый пилот их не заменяет. Текущий результат проверки:
[публичное сравнение](https://learn-sana.pages.dev/examples/comic-page-review/).

## Проверки и воспроизведение

Зависимости Colab закреплены в `requirements-colab.txt`; CUDA PyTorch берётся из
среды Colab. Модель загружается с фиксированной ревизии без стороннего remote code.
Ноутбук скачивает только явно перечисленные файлы обучения с конкретного Git-коммита
и проверяет их SHA-256. Приватные настройки приложения не копируются.

```sh
python train.py --check-data
python check_pipeline.py
python train.py --output /content/sana-comic-run-1
# Только проверка связки Trainer/PEFT: крошечная случайная модель, один шаг на CPU.
# Это НЕ обучение Qwen 4B и не проверка качества.
python train.py --cpu-smoke --output /tmp/sana-comic-smoke
```

ZIP содержит адаптер, токенизатор, точный system prompt, манифест параметров и версий,
результаты до/после, слепое сравнение, ключ и шаблон оценки. Базовые веса в ZIP
не входят. Для повторного использования нужны те же база и ревизия.

Локально 6 ноября проверены все 20 примеров токенизатором выбранной ревизии
(максимум 941 токен) и схемой рабочего API. Проверены маскирование loss, EOS,
padding, запрет тихого обрезания и пересечения тем, HTML-экранирование отчёта.
Один реальный шаг Trainer/PEFT на крошечной случайной CPU-модели изменил адаптер
и сохранил ZIP. GPU-обучение 4B-модели и его качество ещё не проверены.
