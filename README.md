# SANA

Образовательный сайт для первого класса: учителя объясняют темы через пошаговые истории, а дети закрепляют знания в игре.

Сайт: https://sana-learning-stories.wholelynx64.chatgpt.site (приватный доступ через Sites).

## Языки и технологии

- **HTML5** — структура страницы, секции, навигация и встроенный диалог просмотра историй.
- **CSS3** — оформление, адаптивные сетки, мобильная версия и состояния кнопок.
- **JavaScript (ES6+)** — фильтрация уроков, перелистывание историй, проверка ответов и прогресс игры.
- **SVG** — птица, горный пейзаж и декоративные элементы; векторная графика написана прямо в HTML.

Проект работает без фреймворков, npm-зависимостей и этапа сборки. Серверная часть и база данных пока не используются.

## Ресурсы и инструменты

- **Референс SANA**, предоставленный автором проекта: цветовая палитра, настроение, звёзды, горы и орнаментальная композиция. Исходная картинка не включена в сайт.
- **Google Fonts** — шрифты [Cormorant Garamond](https://fonts.google.com/specimen/Cormorant+Garamond) для заголовков и [Manrope](https://fonts.google.com/specimen/Manrope) для интерфейса. Загружаются из внешнего сервиса; при отсутствии сети используются Georgia и Arial.
- **Unicode и системные emoji** — звёзды и иллюстрации демонстрационных историй; внешний вид emoji зависит от устройства.
- **Codex** — разработка HTML, CSS, JavaScript и демонстрационных текстов.
- **Sites** — хранение версий и приватная публикация сайта.
- **Git** — история изменений исходников.
- **Python 3** — локальный HTTP-сервер для предпросмотра; для опубликованного сайта Python не нужен.
- **Node.js** — проверка синтаксиса JavaScript и служебная упаковка публикации; для работы страницы не нужен.

Фотостоки, сторонние библиотеки и генерация изображений не использовались. Птица и пейзаж созданы как SVG.

## Локальный запуск

Из корня проекта выполните:

```sh
python3 -m http.server 4173 --directory dist
```

Откройте http://localhost:4173.

## Структура проекта

- `dist/index.html` — страница и SVG-иллюстрации.
- `dist/style.css` — стили и адаптивная верстка.
- `dist/app.js` — содержание уроков и логика игры.
- `.openai/hosting.json` — конфигурация публикации Sites.

## Текущее наполнение

Включает фильтры предметов, три демонстрационные истории с пошаговым просмотром и игру на сложение. Контент уроков находится в `dist/app.js`. Истории — текстовые прототипы комиксов; загрузка изображений и серверное хранение пока не реализованы.
