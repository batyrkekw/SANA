# SANA

Образовательная платформа для учеников и учителей: учебные темы через комиксы и небольшие игры. Текущие бесплатные пробные уроки посвящены истории Казахстана, математике и физике **8 класса**; сама платформа не ограничена этим классом. Интерфейс, истории, задания, объяснения и подписи для доступности переведены на русский и казахский языки.

## Локальный запуск

Нужны **Node.js 22 или новее** и npm. Из корня проекта:

```sh
npm ci
npm run build
npm start
```

Откройте [http://127.0.0.1:4173](http://127.0.0.1:4173). Сервер отдаёт только каталог `dist` и доступен с локального компьютера. При необходимости порт можно задать переменной окружения `PORT`.

Для просмотра уже собранного `dist` достаточно `node scripts/serve.mjs` из корня проекта — установка зависимостей и повторная сборка не нужны.

Во время работы над стилями запускайте отслеживание изменений в отдельном терминале, оставив `npm start` работающим:

```sh
npm run dev
```

`npm run watch` — аналогичная команда. Она пересобирает CSS, но не запускает HTTP-сервер и не обновляет вкладку автоматически. Перед публикацией выполните `npm run build`, чтобы получить минифицированный CSS.

Готовый каталог `dist` можно разместить на обычном статическом HTTP-хостинге. Node.js и Tailwind в браузере не нужны. Открывайте страницу через HTTP-сервер: JavaScript использует ES-модули, поэтому запуск двойным щелчком через `file://` не поддерживается.

## Технологии

- **HTML5** — структура страницы, навигация и диалог просмотра комиксов.
- **Tailwind CSS 4.3.3** и **@tailwindcss/cli 4.3.3** — локальная сборка utility-классов и стилей из `src/input.css` в `dist/style.css`. Версии закреплены в `package.json` и `package-lock.json`. Tailwind CDN не используется.
- **JavaScript, ES-модули** — локализация, фильтры, просмотр историй и состояние игр; без UI-фреймворка.
- **SVG** — белый голубь по предоставленному визуальному референсу, иллюстрации уроков и пейзаж.
- **Google Fonts** — [Cormorant Garamond](https://fonts.google.com/specimen/Cormorant+Garamond) и [Manrope](https://fonts.google.com/specimen/Manrope). При недоступности внешних шрифтов используются системные запасные шрифты.
- **node:test** — автоматические проверки контента, локализации и игровой логики.

Серверная база данных, аккаунты и внешние игровые API не используются.

## Главная страница и будущая подписка

После блока «Новый взгляд на урок» расположены достижения, блок отзывов учителей, место для будущего видео о SANA и интерактивная витрина возможностей платформы. Показатель **3 000 учителей** предоставлен владельцем проекта. Опубликованных отзывов и готового видеоролика пока нет; вымышленные цитаты не используются.

В блоке отзывов можно создать локальный черновик: указать имя по желанию, роль и впечатление, отредактировать, скачать `.txt` или удалить. Он хранится только в браузере под ключом `sana-review-draft` и **не отправляется на сервер и не публикуется**. Если хранилище недоступно, черновик остаётся в памяти текущей вкладки; интерфейс сообщает об этом.

Витрина содержит три вкладки: пример комикса, интерактивное задание с объяснением и таймер обсуждения на 1, 3 или 5 минут. Таймер можно запустить, приостановить и сбросить. Выбранная вкладка, попытка ответа и таймер сохраняются при переключении языка, но сбрасываются при перезагрузке. Отсчёт рассчитывается по времени завершения, чтобы не накапливать задержку в фоновой вкладке.

Палитра сочетает насыщенные золотые акценты с чередующимися белыми и тёмно-синими секциями. Первый экран состоит из двух колонок: слева — заголовок «Образовательная платформа для учителей», описание и две кнопки; справа — белый SVG-голубь, надпись SANA и слоган. На узких экранах колонки располагаются друг под другом.

Существующие комиксы обозначены как бесплатные пробные уроки. Расширенная библиотека и дополнительные возможности запланированы для подписки. После игр добавлены три предварительных тарифа:

| Тариф | Токены | Планируемое наполнение |
| --- | --- | --- |
| Обычный | 7 000 | Только пакет токенов |
| Про | 10 000 | Интерактивные игры, конструктор викторин, шаблоны уроков |
| Плюс | 13 000 | Возможности «Про», персональные сценарии уроков, общая библиотека команды, экспорт в PDF |

Кнопки тарифов открывают описание выбранного пакета и позволяют перейти к бесплатным урокам. **Подключение подписки, оплата, учёт и списание токенов пока не реализованы**; цены, период действия и правила расходования не заданы. Перечисленные функции тарифов — планируемые, а не уже доступные инструменты.

«Плюс» выделен золотым оформлением карточки и диалога. Под тарифами раскрывается таблица сравнения, затем идут ответы на частые вопросы. Закреплённая навигация отмечает текущий раздел. Все новые блоки доступны на русском и казахском.

## Содержание и поведение

В библиотеке **3 комикса по 4 панели** и **3 игры по 5 заданий**:

| Предмет | Комикс | Игра |
| --- | --- | --- |
| История Казахстана | «Алаш: страницы 1917 года» — съезды, автономия и Алаш-Орда | «Архив 1917» — восстановление событий и понятий |
| Математика | «Код двух корней» — квадратные уравнения и дискриминант | «Открой лабораторию» — формулы, дискриминант и число корней |
| Физика | «Свет по закону Ома» — ток, напряжение и сопротивление | «Запусти станцию» — закон Ома и измерительные приборы |

В игре после ошибки можно выбрать другой ответ. Следующее задание открывается после верного ответа; результат отдельно показывает число ответов с первой попытки. Повторное нажатие не начисляет дополнительные баллы.

Переключатель **РУС / ҚАЗ** меняет язык на всей странице и внутри открытого комикса. Выбор языка сохраняется в `localStorage` под ключом `sana-language`; если хранилище недоступно, переключение продолжает работать в текущей вкладке. По умолчанию выбран русский язык.

Прогресс игр хранится **только в памяти страницы**, отдельно для каждого предмета. Переключение языка или предмета сохраняет текущую попытку. Перезагрузка страницы сбрасывает игровой прогресс. Кнопка повторной игры сбрасывает только выбранный предмет. Смена языка также сохраняет открытую панель комикса.

При загрузке страницы голубь плавно поднимается и слегка двигает крыльями: одноразовая анимация длится **2,2 секунды**. В блоке «Сложное становится понятным» шаги **01 → 02 → 03** появляются последовательно при первом попадании блока в область просмотра. При системной настройке `prefers-reduced-motion: reduce` анимации отключены, содержание сразу доступно.

## Структура проекта

```text
dist/
  index.html          Страница и доступная разметка
  style.css           Готовые стили; результат npm run build
  app.js              Интерфейс, события, комиксы и переключение языков
  plans.js            Предварительные тарифы и диалог их описания
  enhancements.js     Сравнение тарифов и активный раздел навигации
  showcase.js         Витрина, пробный вопрос и таймер класса
  reviews.js          Форма и локальное хранение черновика отзыва
  *-i18n.js           Переводы новых блоков RU/KK
  content.js          Комиксы, задания, объяснения и ссылки на источники
  i18n.js             RU/KK-переводы интерфейса и функции локализации
  game-state.js       Независимая логика попыток, прогресса и результата
  illustrations.js    SVG-голубь и иллюстрации предметов
src/
  input.css           Исходные стили, Tailwind, адаптивность и анимации
  hero.css            Первый экран: текст слева, птица и SANA справа
  landing.css         Дополнительные секции главной страницы и тарифы
  section-themes.css  Чередование светлых и тёмных секций
  enhancements.css   Премиальный тариф, сравнение, FAQ и навигация
  showcase.css       Интерактивная витрина возможностей
  reviews.css        Блок отзывов и форма черновика
scripts/
  serve.mjs           Локальный HTTP-сервер для dist
tests/
  content.test.mjs     Полнота локализации и целостность учебного контента
  game-state.test.mjs  Игровые сценарии и защита состояния
package.json          Команды и закреплённые версии зависимостей
package-lock.json     Воспроизводимая установка через npm ci
.gitignore            Исключения зависимостей и временных файлов
.openai/hosting.json   Сохранённая конфигурация Sites
README.md             Документация проекта
```

Редактируйте стили в `src/input.css` и подключённых CSS-файлах из `src`, затем запускайте сборку. Содержание уроков меняется в `dist/content.js`, общие подписи — в `dist/i18n.js` и импортированных словарях, состав предварительных тарифов — в `dist/plans.js`.

## Проверки

```sh
npm test
```

Тесты проверяют совпадение RU/KK-ключей и параметров переводов, наличие переводов для HTML и ARIA-подписей, все 12 панелей и 15 заданий, корректность индексов и различимость вариантов ответа. Игровые проверки охватывают завершение каждого предмета, ошибки, запрет пропуска нерешённых вопросов, повторные нажатия, подсчёт первых попыток, независимость предметов и перезапуск.

## Публикация

Конфигурация `.openai/hosting.json` сохранена; каталог публикации — `dist`. При проверке существующий проект Sites вернул `NOT_FOUND`, поэтому текущие изменения подготовлены локально и **не опубликованы**. Обновление ранее опубликованного адреса не подтверждено. Готовый `dist` можно использовать после восстановления доступа к проекту Sites или на другом статическом хостинге.
