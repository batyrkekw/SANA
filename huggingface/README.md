# SANA Story Lab на Hugging Face ZeroGPU

Подготовлен отдельный сервис для проверки Qwen3-4B и будущего адаптера.
**GPU-обучение ещё не выполнено; публичная SANA на него не переключена.**
Аккаунт Hugging Face новый и пока не проходит требование возраста >30 дней для
бесплатного ZeroGPU. Space не создан; токен доступа ещё не сохранён. После выполнения
требований возраста, подтверждения почты и статуса аккаунта доступ надо проверить
через API. Платные ресурсы не заказываются. Текущая SANA работает через Cloudflare.

## Публикация

Локальный `.env.huggingface.local` (игнорируется Git, права 0600):

```dotenv
HF_TOKEN=...
```

Токен используется локально для создания/обновления только `<owner>/sana-story-lab`.
Имя владельца определяется через whoami. Токен публикации не копируется в Space,
в браузер, в ноутбук, в Cloudflare или в GitHub. Отдельный ключ API генерируется
локально и сохраняется как секрет Space.

```sh
backend/.venv/bin/python huggingface/manage.py check
backend/.venv/bin/python huggingface/manage.py package
backend/.venv/bin/python huggingface/manage.py publish
backend/.venv/bin/python huggingface/manage.py status
```

Публикация явно запрашивает только `zero-a10g` — это API-идентификатор ZeroGPU,
а не заказ выделенного A10G. При отказе или необходимости оплаты скрипт останавливается.
Он не создаёт платные Inference Endpoints, не включает CPU/GPU upgrade и не меняет
платёжные настройки. Код Space публичный, как код SANA; реальные уроки и данные
аккаунтов в репозиторий не загружаются. Существующий Space без метки этого проекта
не перезаписывается. Для выгрузки используется явный список файлов.

## Контракт и проверка

`/status` сообщает фактическую базовую модель, ревизию и наличие адаптера.
`fine_tuned: false` означает, что базовая модель не дообучена. `quality_approved`
остаётся false до независимой оценки; наличие файла адаптера не доказывает качество.

`/story` требует `X-SANA-Key` и нормализует данные до выделения GPU. Принимает
subject, topic, grade, language, instructions и необязательные kind=comic, length=4.
Одна попытка генерации, без повторов на ошибку. Ответ содержит контент, происхождение,
число токенов и время инференса. Английские визуальные описания и структура проверяются
тем же экспериментальным контрактом, что использован при подготовке Colab.
Это не автоматическая проверка научной точности или юмора.

Перед подключением к сайту нужно проверить реальный GPU-ответ, RU/KK, задержку,
расход доступной квоты, обработку очереди и исчерпания лимита. Локальные проверки
без GPU не заменяют эту проверку. Публичный worker сейчас продолжает использовать
Cloudflare; маршрутизация через HF и резервное переключение пока не добавлены.

После обучения и оценки можно загрузить адаптер в отдельный HF model repo и указать
в Space `SANA_ADAPTER_REPO` и точный `SANA_ADAPTER_REVISION`. Код проверяет соответствие
базы, тип LoRA, rank и модули; загружает safetensors, не произвольный Python-код.
Для приватного адаптера понадобится отдельный токен только для его чтения.

## Ограничения

По [документации ZeroGPU](https://huggingface.co/docs/hub/spaces-zerogpu), бесплатный
личный аккаунт в хорошем состоянии, старше 30 дней и с подтверждённой почтой может
разместить до двух ZeroGPU Spaces. Квота — 5 минут GPU в сутки; есть очереди.
[API-квота](https://huggingface.co/docs/hub/spaces-api-endpoints#zerogpu-spaces)
расходуется для аккаунта, чьим HF-токеном подписаны вызовы. Один токен backend не
даёт отдельные пять минут каждому пользователю SANA. Пропускная способность для
80–100 комиксов/сутки не подтверждена. Colab остаётся средой обучения, а не сервером.

## Локальные проверки

```sh
backend/.venv/bin/python huggingface/test_service.py
backend/.venv/bin/python huggingface/test_deploy.py
# В изолированной среде с зависимостями Space:
python huggingface/test_api.py
```

Тест API запускает настоящий локальный Gradio HTTP/queue с тестовой функцией вместо
модели. Он проверяет авторизацию до вызова GPU, формат запроса и метаданные состояния.
Это проверка транспорта, не успешная генерация реальной Qwen на ZeroGPU.

6 ноября 2026: прошли 7 CPU-проверок валидации и публикации, проверка реального
HTTP/queue Gradio с тестовой функцией и импорт/создание крошечной Qwen + PEFT
с закреплёнными зависимостями Space. Проверены токенизатор фиксированной ревизии,
авторизованный запрос и отказ неавторизованному/некорректному запросу до вызова
генератора. Полные веса Qwen 4B и GPU в этих локальных проверках не использовались.
