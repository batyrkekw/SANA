# Проверка комиксов перед дообучением

6 ноября 2026 проведены реальные запросы в Cloudflare. Результаты и точные промпты:
`results/2026-11-06/`. Визуальное сравнение: `/examples/comic-page-review/`.

**Дообучение не запущено: проверка качества не пройдена.** Пользователь поставил
проверку качества и стоимости перед обучением. Низкая стоимость подтверждена,
но критические ошибки предметов/состояний остаются. Это не обученные веса и не
доказательство улучшения за счёт обучения. Экспериментальные изменения промптов
не перенесены в рабочую генерацию; исходный рабочий код сохранён.

## Как воспроизвести

Используется действующий `CLOUDFLARE_API_TOKEN`, либо локальный OAuth Wrangler
после `wrangler whoami`. Ключи не печатаются. Запросы расходуют общую AI-квоту.
Каждый запуск делает максимум один вызов текстовой модели, одну попытку исправления
описаний и один запрос изображения. HTTP-клиент не повторяет ошибочные запросы.

```sh
backend/.venv/bin/python cloudflare/benchmark_comic.py \
  --case benchmarks/comics/ice.json --out .tooling/comic-benchmark/new-run

# Изолированная проверка рисунка с тем же выверенным текстом и точным промптом.
backend/.venv/bin/python cloudflare/benchmark_comic.py \
  --case benchmarks/comics/ice.json \
  --script benchmarks/comics/ice-editorial-compact.json \
  --page-prompt benchmarks/comics/results/2026-11-06/ice-compact-512-prompt.txt \
  --seed 314159 --size 512 --out .tooling/comic-benchmark/new-image-only-run
```

Не перезаписывайте каталог существующего результата. Новый полный прогон использует
рабочие промпты из текущего кода; `ice-v2` использовал экспериментальные инструкции,
которые затем отклонены. Поэтому их результаты не следует выдавать за результат
нынешней production-цепочки. Все сравнения используют одну модель изображений.

В паре editorial-512/editorial-1024 совпадают сценарий, image prompt и seed,
различается разрешение. В других случаях менялись сценарий и инструкции; это поиск
рабочего подхода, не контролируемый рейтинг качества модели.

## Расход

Qwen в полном экспериментальном прогоне вернул `usage.neurons`:
47.83140563964844 за сценарий и 28.965503692626953 за исправление промптов.
Сумма текста — 76.79690933227539. Изображение не вернуло отдельный счётчик Neurons;
по тарифу 512×512 стоит 26.05, 1024×1024 — 104.20. Полный пример: примерно 102.85.
Числа `*_estimate` — расчёт по тарифу; `*_reported`/`usage.neurons` — ответ провайдера.
Это не аудит счёта Cloudflare и не среднее по всем темам. Не следует умножать
только стоимость рисунка на число комиксов и забывать текст, исправления и повторы.

80 таких полных комиксов — примерно 8228 Neurons; 100 — около 10285, что уже
превышает бесплатные 10000. Это ориентир на одном примере без других запросов.

## Набор для будущего обучения

`ice-editorial*.json` — один оригинальный текстовый пример SANA в двух вариантах
описаний; не два независимых обучающих примера. Он написан ассистентом и не прошёл
оценку юмора школьниками. Сгенерированные изображения **не являются одобренными
целями** и не включаются автоматически в обучающий набор.

Для начала нужны исправленные визуальные эталоны, больше проверенных сценариев
RU/KK для нужных возрастов, отдельные темы для проверки и доступный GPU-сервис.
LoRA текста учит диалогу и структуре сюжета; LoRA рисунка — стилю и визуальным
признакам. Одна не заменяет другую и не гарантирует фактологическую точность.

Текущий Cloudflare endpoint не принимает собственную LoRA FLUX.2 klein или Qwen3.
В подключённой конфигурации проекта GPU-сервиса для обучения нет. Платные ресурсы
не создавались. Для собственных весов надо решить и обучение, и последующий хостинг.

После выбора пользователем бесплатного Colab подготовлен отдельный
[текстовый пилот](../../training/comics/README.md): 16 оригинальных сценариев для
обучения и 4 для проверки. Он не использует проваленные изображения и не меняет
этот результат проверки визуального качества. Настоящий GPU-запуск ещё не выполнен.
