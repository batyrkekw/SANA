# Отчёт о реализации SANA

## 1. Реализовано

FastAPI API, интеграция Supabase Auth, личный кабинет RU/KK, профиль, настройки, внутренние тарифы, баланс и журнал токенов, собственные материалы, генерация через очередь, локальные текстовый и графический провайдеры. Поиск, фильтры, пагинация, переименование и подтверждаемое удаление материалов; сохранённый контент отображается по его структуре. Реальных платежей нет.

## 2. Добавленные компоненты

`backend/app/`: main, config, db, models, security, schemas, services, worker, ai, storage, manage, smoke. `backend/tests/` — интеграционные тесты с настоящим PostgreSQL и отдельными схемами. `backend/scripts/queue_smoke.py` — реальный тест Redis/Celery/AI. `dist/auth.*`, `account.*`, session, platform-common, platform-i18n, landing-account; `src/platform.css`, vendor entry/bundler; `config/plans.json`, Ollama.Modelfile; Dockerfile/Compose, `.env.example`, Playwright и GitHub Actions.

В тестах проверены подпись, алгоритм, issuer, audience, exp, роль, anonymous и чужие ID.

## 6. Токены

Баланс только на сервере. Начальное начисление один раз, резерв вместе с job в одной транзакции, списание только при атомарном сохранении успешного результата, полный возврат при ошибке/отмене queued. Блокировка счёта и уникальные операции защищают от гонок и повторов. БД служит outbox, watchdog возвращает резерв зависших заданий. Проверены гонки из 8 запросов, повторная доставка, отказ AI, брокера и истечение deadline. Тариф/стоимость задаются конфигурацией; администратор не может случайно превысить лимит при начислении.

## 7. Модели

Qwen3:4b через Ollama; локальный alias sana-qwen3:4b использует контекст 8192. Ответ ограничивается JSON-схемой и проверяется Pydantic. Текст правильного варианта преобразуется сервером в индекс, числовой вариант сверяется с arithmetic_check. Это ограниченная проверка, не гарантия предметной точности.

Для изображений выбрана SD 1.5 (CreativeML OpenRAIL-M), 512 px: меньшая нагрузка на Mac 16 GB, чем у SDXL. Веса fp16, вычисления MPS/CPU float32, CUDA float16. Pipeline переиспользуется worker. [Лицензии, ограничения и команды](AI.md).

## 12. Ограничения

Supabase подключён, новая регистрация через Custom SMTP, подтверждение почты, вход и создание профиля проверены. Создание урока ранее подтверждено пользователем. Письмо восстановления доставлено, но попало в спам: доставляемость во «Входящие» другим пользователям не гарантируется. Для публичного запуска нужны сервис транзакционных писем с проверенным доменом и публичный HTTPS-адрес приложения вместо localhost. Google OAuth не настроен. CUDA и Docker CPU inference не проверялись на соответствующем оборудовании. Качество RU/KK, педагогика, научная точность и визуальная связность комиксов требуют проверки преподавателем. В production нужны резервное копирование, наблюдение за worker и сборщик потерянных файлов после аварийного завершения процесса. Командная библиотека, PDF, платежи и приоритет очереди не реализованы и не представлены как рабочие возможности.

## 13. Ручные действия

Проверка новой регистрации завершена. Перед публичным запуском настроить домен приложения и отправителя, проверить доставляемость писем на разные почтовые сервисы. Для тестового ящика можно отметить доставленное письмо как «Не спам»; это не доказывает доставляемость во «Входящие» другим получателям. Полное восстановление со сменой пароля проверить отдельно, если требуется. При необходимости настроить Google provider. При переносе на другой компьютер заполнить локальный `.env` из Dashboard и перезапустить API; SMTP-пароль остаётся в Supabase и не переносится в `.env`. Пароли и секретные ключи не нужно отправлять в чат. Подробности — в README.

## Подготовка Cloudflare, 29 октября 2026

Добавлен отдельный Python Workers runtime с общими FastAPI-маршрутами, моделями, проверкой
владельца и транзакциями токенов. Pages проксирует API через service binding; Hyperdrive
подключает приватную схему Supabase, Queues исполняет задания, Cron повторяет отправку
outbox и возвращает резерв зависших заданий. Облачный Qwen3-30B проверен реальным запросом;
установлен общий предел 20 новых заданий в сутки UTC. Облачные изображения отключены.

Проверки: 42 Python-теста с PostgreSQL, 21 Node-тест и 5 браузерных тестов прошли.
Локальный Workers runtime проверен через API и полный цикл queue → Workers AI → сохранённый
материал в отдельной тестовой схеме. Временный Worker в Cloudflare подтвердил совместимость
FastAPI/SQLAlchemy и был удалён. Созданы Pages-проект `learn-sana`, очередь и публичный CA
сертификат. Данные в Supabase ещё не перенесены: требуется правильный пароль базы.
Адрес `learn-sana.pages.dev` пока зарезервирован, работающий production deployment не заявляется.
Порядок переноса и публикации описан в [cloudflare/README.md](../cloudflare/README.md).
