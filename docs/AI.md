# AI в SANA

## Публичный сайт: всё в облаке

Текст урока и сценарий комикса создаёт **Qwen3-30B-A3B-FP8** через Cloudflare Workers AI.
Иллюстрации создаёт **FLUX.2 klein 4B**, одна страница 512×512 за один запрос.
Для четырёх сцен задаётся сетка 2×2: каждый кадр имеет примерно 256×256 пикселей.
Поддерживаются также 1–3 сцены. Конфигурация — `cloudflare/src/comic_art.py`.
Первый кадр больше не передаётся повторно: все сцены входят в общий промпт страницы.
Реплики RU/KK и пояснения выводятся отдельными HTML-карточками в порядке чтения.
Одна приватная картинка служит обложкой и страницей урока, повторно используется из кеша.
Старые материалы с отдельными кадрами остаются совместимыми.

[Qwen3-30B-A3B](https://huggingface.co/Qwen/Qwen3-30B-A3B) и
[FLUX.2 klein 4B](https://huggingface.co/black-forest-labs/FLUX.2-klein-4B)
имеют открытые веса под Apache-2.0, допускающей коммерческое использование при соблюдении условий.
Лицензия модели не означает неограниченно бесплатное облачное исполнение.

Задание проходит PostgreSQL outbox → Cloudflare Queue → Workers AI → приватный KV.
Mac, Ollama, Celery и Redis не участвуют в публичной генерации. Ожидание отправки в очередь
может занимать до минуты. Открытие готового материала не запускает модель повторно.

Сценарий проверяется по JSON-схеме, языку и числу кадров. Если визуальные описания не являются английскими предложениями
(включая слитные CamelCase-строки), Qwen делает одну попытку исправления описаний. Разрешён один повтор временной
ошибки генератора изображений на задание, без повторов при исчерпании квоты или фильтрации.
Ошибка возвращает весь резерв; частичный комикс не публикуется. Это техническая проверка,
а не автоматическое доказательство правильности учебного содержания.

## Бесплатная квота

Workers Free включает **10 000 Neurons в сутки на весь аккаунт**, обновление в 00:00 UTC.
Платный тариф не включается приложением. Одна страница klein 4B 512×512 стоит около
**26.05 Neurons**, плюс текст Qwen и возможный повтор; прежние четыре dev-кадра с референсами
стоили около 4125. Это экономия примерно в 158 раз именно на изображениях, не на всей цепочке.
При 60 Neurons на текст (сценарий оценки, не измеренный средний расход) 100 комиксов потребуют
около 8605 Neurons. Длинные ответы, исправление промптов, повторы и другие приложения расходуют
тот же лимит. Гарантии 100 бесплатных комиксов в день нет. Квота исчерпана — запрос отклоняется,
резерв возвращается. Страница 1024×1024 была бы вчетверо дороже по картинкам и сейчас не используется.

Новый облачный комикс до четырёх кадров стоит **22 токена SANA** (12 сценарий + 10 страница).
Локальная генерация отдельных картинок сохраняет прежний расчёт. Общий защитный лимит —
100 новых заданий в сутки; это максимум заданий, а не обещание доступного GPU.
[Актуальная тарификация Cloudflare](https://developers.cloudflare.com/workers-ai/platform/pricing/).

### Администратор

Серверный `profiles.is_admin` задаётся только CLI `python -m app.manage set-admin
--supabase-id UUID --admin true` (для отключения `false`). Публичные настройки и Supabase
user metadata не управляют им. API возвращает `tokens.unlimited`, интерфейс показывает ∞.
Новые задания администратора имеют стоимость 0 с обычными идемпотентными записями журнала;
числовой баланс не подменяется огромным числом. Старые резервы завершаются по своей исходной стоимости.
Права на чужие материалы не выдаются. Общие квоты, лимиты числа кадров и активных заданий сохраняются.
Перед выкладкой новой версии выполнить `backend/.venv/bin/python cloudflare/upgrade.py`;
это Alembic-обновление существующей схемы, не повтор первоначального переноса данных.

На одном одинаковом синтетическом описании пророста фасоли dev (6.95 с) и klein 9B (1.54 с)

но это субъективная оценка одного примера, не универсальный рейтинг и не проверка всех предметов.
Все запросы исполнялись на Cloudflare. Первый полный тест dev создал четыре кадра за 43.4 с,

После этого добавлена проверка минимум восьми английских слов и переписывание плохих описаний. Ранее опубликованный образец klein 4B сохранён с пометками
ошибок, чтобы не выдавать старые изображения за новый результат.

## Мемы и дообучение: следующий этап

Сначала нужна библиотека предоставленных автором мемов: оригинальное изображение, смысл шутки,
уместные учебные ситуации, возрастная группа, язык и примеры неуместного использования.
Qwen выбирает подходящий пример и пишет сценарий; генератор получает выбранный референс.
Подписи следует накладывать отдельно, чтобы не портить русский и казахский текст. Точное
воспроизведение мем-шаблона надёжнее делать композицией оригинала, а не перерисовкой нейросетью.

Для последующего обучения подходит [FLUX.2 klein base 4B](https://huggingface.co/black-forest-labs/FLUX.2-klein-base-4B):
недистиллированная базовая версия под Apache-2.0. Это отдельный checkpoint, сейчас на сайте
используется быстрая дистиллированная версия. Нельзя просто загрузить LoRA базовой версии
в текущий Cloudflare endpoint: для собственного обучения/инференса понадобится совместимый GPU-сервис.

Набор данных следует хранить вне Git: страница, четыре описания сцен, язык и класс,
проверенные факты, реплики, автор/разрешение на мем, оценка соответствия и пометка approved/rejected.
В обучение попадают только одобренные примеры; проверочный набор хранится отдельно.
Дообучение нужно оценивать после сбора одобренных и отклонённых примеров. LoRA изображения
поможет закрепить рисунок/персонажа, но само по себе не научит уместному юмору или фактам урока.
Отдельный набор проверок должен измерять предметную точность, следование сценарию, постоянство
персонажей, уместность шуток, читаемость RU/KK и стоимость. Для предметов с точной геометрией
и формулами стоит использовать проверяемые SVG/шаблоны вместо свободной генерации.

Загрузка своих мемов и обучение сейчас не реализованы: исходные мемы ещё не предоставлены.
У Cloudflare нет документированного пути загрузки LoRA для выбранного FLUX или Qwen-Image;
[поддержка LoRA](https://developers.cloudflare.com/workers-ai/features/fine-tunes/loras/)
ограничена совместимыми моделями. Обучение и отдельный GPU нельзя обещать постоянно бесплатными.

## Локальная разработка (не участвует в публичном сайте)

Для текста сохранён OpenAI-compatible адаптер Ollama / llama.cpp / LM Studio.
Выберите `SANA_LLM_BASE_URL` и `SANA_LLM_MODEL` явно. На этом Mac ранее использовался Qwen3:4b.
Локальная генерация изображений по умолчанию выключена; устаревший предвыбранный checkpoint
убран. Необязательный Diffusers-адаптер сохранён для разработки, но требует явного выбора
совместимого `SANA_IMAGE_MODEL_ID`, установки AI-зависимостей, подготовки весов и проверки.
Подмена ID не гарантирует поддержку новой архитектуры. Веса не скачиваются при обращении к API.

## Историческая проверка отдельных кадров FLUX.2 dev

Повторный реальный тест двух кадров: 34.5 с после получения задания из очереди,
37.2 с ожидания outbox, два JPEG 512×512, модель в метаданных `flux-2-dev`,
одно списание 32 внутренних токенов, резерв 0. Описания стали нормальными предложениями.
Семя и корешок теперь связаны, но генератор изобразил два корешка вместо одного,
а в первом кадре пропустил чашку. Эти несоответствия явно отмечены в
[публичном пилоте](https://learn-sana.pages.dev/examples/seed-root/).
Предметная точность ещё не решена полностью. Дообучение на мемах само по себе это не исправит.
Тесты выполнялись под временными отдельными профилями; их записи и KV-копии удаляются после экспорта.

## Проверка одной страницы, 1 ноября 2026

Миграция `a8c4e102b937` применена к облачной схеме без изменения балансов.
Тест под разрешённым аккаунтом администратора прошёл постановку в реальную облачную очередь
со стоимостью 0, без резерва и списания. Локальные API/worker/БД на время облачной проверки
были остановлены. Workers AI отклонил генерацию: отдельный минимальный запрос подтвердил
HTTP 429 / code 4006 — исчерпаны сегодняшние 10 000 Neurons.
Поэтому новое изображение и его визуальное качество ещё не проверены на живой модели.
Сброс квоты — 00:00 UTC / 05:00 Алматы. Платный тариф не включался.
Добавлен отдельный код `ai_daily_quota_exhausted` с сообщением RU/KK и без повторов при квоте.
Сохранение одной страницы, совместимость старых кадров, приватность, кеш и нулевая стоимость
проверены автоматическими тестами; это не заменяет визуальный тест после сброса квоты.
